Design and Analysis of Algorithms: Theoretical Foundation

1. Problem Formulation

Let $G = (V, E, W)$ be a directed debt multigraph where each directed edge $(u, v) \in E$ with positive weight $W(u, v)$ denotes that person $u$ owes person $v$ an amount $W(u, v)$.

Net Balance Definition ($B_i$):
B_i = \sum_{(u, i) \in E} W(u, i) - \sum_{(i, v) \in E} W(i, v) = \text{Incoming} - \text{Outgoing}

Conservation Invariant: In any closed economy of debts, the sum of all net balances is strictly zero:

\sum_{i \in V} B_i = 0

2. Greedy Paradigm with Max-Heaps

The greedy algorithm partitions non-zero balances into two sets:

  • Creditors Set: $\mathcal{C} = \{ i \in V \mid B_i > 0 \}$ maintained in a Max-Heap.
  • Debtors Set: $\mathcal{D} = \{ j \in V \mid B_j < 0 \}$ maintained in a Max-Heap using $|B_j|$.
Greedy Heap Settlement Algorithm
Algorithm CashFlowMinimizerGreedy(V, E, W):
  1. For each v in V: B[v] = 0
  2. For each (u, v, w) in E:
       B[u] -= w
       B[v] += w
  3. Initialize MaxHeap Creditors, MaxHeap Debtors
  4. For each v in V:
       if B[v] > 0: Creditors.push(B[v], v)
       if B[v] < 0: Debtors.push(-B[v], v)
  5. While Creditors not empty and Debtors not empty:
       (c_amt, c_node) = Creditors.pop()
       (d_amt, d_node) = Debtors.pop()
       settle = min(c_amt, d_amt)
       RecordTransaction(d_node -> c_node, settle)
       if c_amt - settle > 0: Creditors.push(c_amt - settle, c_node)
       if d_amt - settle > 0: Debtors.push(d_amt - settle, d_node)
  6. Return SettledTransactions

Greedy Time Complexity

O(|V| \log |V| + |E|)

In each step, at least one person's balance becomes zero. Therefore, at most $|V| - 1$ settlements occur, each taking $O(\log |V|)$ heap operations.

Greedy Space Complexity

O(|V|)

Requires memory proportional to the number of participants to store net balances and heap elements.

3. NP-Hardness Proof & Optimal Dynamic Programming

Theorem: Minimizing the total number of cash transactions is NP-Hard.

Reduction from Subset-Sum / Partition Problem:

Each transaction can reduce at most one debtor or creditor to balance zero, except when a subset of individuals has balances that sum precisely to zero! If a subset $S \subseteq V$ satisfies $\sum_{i \in S} B_i = 0$, that subset can be completely settled internally in $|S| - 1$ transactions without interacting with the rest of the group.

Therefore, if the set of non-zero balance individuals can be partitioned into $k$ disjoint subsets $S_1, S_2, \dots, S_k$ such that $\sum_{v \in S_j} B_v = 0$ for all $j$, then the total minimum transactions required is:

\text{Minimum Transactions} = |V_{\text{active}}| - k_{\max}

To minimize the number of transactions, we must maximize $k$ (the number of disjoint zero-sum subsets). Finding whether a zero-sum subset exists is equivalent to the classical Subset Sum Problem, which is known to be NP-Complete. Hence, the transaction minimization problem is NP-Hard.

Why Greedy Can Be Sub-Optimal (The Counter-Example)

Consider 5 participants with the following net balances:

Alice: +4 Bob: +3 Charlie: +2 Dave: -5 Evan: -4
Greedy Algorithm ($4$ transactions)
  1. Max Debtor Dave (-5) & Max Creditor Alice (+4) ➔ Settle ₹4. Dave has -1 left.
  2. Max Debtor Evan (-4) & Max Creditor Bob (+3) ➔ Settle ₹3. Evan has -1 left.
  3. Max Debtor Dave (-1) & Charlie (+2) ➔ Settle ₹1. Charlie has +1 left.
  4. Evan (-1) & Charlie (+1) ➔ Settle ₹1.
Total = 4 Transactions
Optimal DP Partition ($3$ transactions)

Recognizes two disjoint zero-sum subsets ($k=2$):

  • Subset 1: {Alice (+4), Evan (-4)} ➔ Settle ₹4 in 1 transaction.
  • Subset 2: {Bob (+3), Charlie (+2), Dave (-5)} ➔ Settle in 2 transactions (Bob pays Dave ₹3, Dave pays Charlie ₹2).
Total = (5 - 2) = 3 Transactions (Global Optimal!)
